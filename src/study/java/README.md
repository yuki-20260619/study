# Java学習

Javaの基礎学習・コーディング練習の記録をGitHubにまとめています。

## 学習目的

- Javaの基礎力を身につける
- 自力でプログラムを書く力を身につける
- 開発寄りのキャリアを目指す
- 将来的に業務改善アプリをポートフォリオとして作成する

## 学習環境

- Windows 11
- IntelliJ IDEA
- OpenJDK 21
- Git / GitHub
