# Java学習

Javaの基礎学習・コーディング練習の記録をGitHubにまとめています。

## 学習目的

- Javaの基礎力を身につける
- 自力でプログラムを書く力を身につける
- 開発寄りのキャリアを目指す
- 将来的に業務改善アプリをポートフォリオとして作成する

## 学習環境

- Windows 11
- IntelliJ IDEA
- OpenJDK 21
- Git / GitHub

---

## ディレクトリ構成

```text
src/study/java/
├─ practice/
│  └─ standardInput/
│     ├─ day01_20260821/
│     ├─ day02_20260822/
│     └─ ...
└─ study/
   ├─ day01_20260619/
   ├─ day02_20260620/
   ├─ day03_20260621/
   └─ ...
```
**practice**

Javaの文法やアルゴリズムを、自分で問題を解きながら定着させるための練習記録です。<br>
<br>
学習サイトの問題文や解答コードは掲載せず、問題数・正答率・学習内容・振り返りを中心に記録します。<br>
自分で作成した練習コードについては、必要に応じて保存します。<br>

**study**

Javaの基礎から順番に学習した内容を、Dayごとに記録するディレクトリです。<br>
<br>
クラス・継承・例外処理・ファイル操作などの基礎から、<br>
簡単なアプリケーション開発へ段階的に進めています。<br>
