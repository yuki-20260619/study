# SQL学習

SQLの基礎学習・コーディング練習の記録をGitHubにまとめています。

## 学習目的

- データベースの基本的な仕組みを理解する
- SQLを使用したデータの登録・取得・更新・削除を習得する
- テーブル設計や複数テーブルを扱うSQLの知識を身につける
- 将来的にJavaアプリケーションとデータベースを連携させるための基礎を習得する

## 学習環境

- OS：Windows 11
- データベース：MySQL
- IDE：IntelliJ IDEA
- Java：OpenJDK 21
- バージョン管理：Git / GitHub
